# リユース推進部 商品管理台帳

**対象拠点**: 府中センター（リユース推進部）  
**現在バージョン**: v6  
**動作環境**: Chrome（ローカルファイルをブラウザで直接開いて使用）

---

## 概要

ブラウザ上で動作するリユース商品の管理ツールです。商品の入荷登録から売上確定・棚卸・古物台帳まで、日常業務に必要な機能を1ファイルに集約しています。サーバー不要で、データはブラウザのlocalStorageに自動保存されます。

---

## 起動方法

`reuse_ledger_v6.html` をChromeで開くだけで使用できます。インストール不要です。

> ブックマークに登録しておくと毎回ダブルクリックせずに済みます。

---

## 主な機能

### 1. 商品台帳

全登録商品の一覧表示。テキスト検索・部門/ステータス/ランクによるフィルタリングができます。50件ずつページ表示するため、件数が増えても動作が重くなりません。

### 2. 新規入荷登録（4ステップ）

画面中央のポップアップで開きます。

| ステップ | 内容 |
|---|---|
| Step 1 | 部門選択 ＋ 商品情報（品名・ブランド・型番・入荷日・棚番号・備考） |
| Step 2 | ランク選択（単品T / まとめM）＋ 状態 ＋ 仕入価格 |
| Step 3 | 古物台帳情報（個人／法人・氏名・住所・確認書類） |
| Step 4 | 確認画面 → 登録実行 |

**管理番号の自動生成ルール**

```
FC-YYMMDD-[部門コード]-[連番3桁]
例: FC-260508-S-001
```

### 3. 商品詳細・編集

商品行をクリックすると右パネルが開きます。

- バーコード表示・感熱プリンター印刷
- **ステータス・棚番号はパネル上で即時変更可能**（選択・入力するだけで自動保存）
- 編集モードで全フィールドを修正
- 在庫中の商品は売上登録フォームを表示

### 4. 売上管理

- 月間目標（¥3,000,000）に対する達成率・残額の表示
- 販路別売上グラフ
- 販売済み一覧テーブル（粗利計算付き）

### 5. 売上分析（4タブ）

| タブ | 内容 |
|---|---|
| 概要 | 総売上・総粗利・粗利率・販路別/部門別ドーナツグラフ |
| 販路別 | 売上・粗利の棒グラフ ＋ 詳細テーブル |
| 部門別 | 売上ランキンググラフ ＋ 詳細テーブル |
| 予算達成 | 月間予算設定・達成率・日次実績グラフ |

### 6. 棚卸

- 在庫商品のチェックリスト（部門フィルター付き）
- チェック状態はlocalStorageに保存（ブラウザを閉じても保持）
- リセットボタンで次回棚卸に備えられる

### 7. 古物台帳

古物営業法 第16条準拠の取引記録一覧。全登録商品を逆順で最大300件表示します。

### 8. Excelインポート

`.xlsx` / `.xls` ファイルをドラッグ＆ドロップで取り込めます。プレビュー確認後に「置き換え」または「追加（重複スキップ）」を選択して実行します。

**デフォルト列マッピング**（「無題のスプレッドシート.xlsx」に合わせた設定）

| 項目 | 列 |
|---|---|
| ヘッダー行 | 3行目 |
| 管理番号 | 1列目 |
| 入荷日 | 2列目 |
| カテゴリ | 3列目 |
| 品名 | 4列目 |
| ランク | 5列目 |
| 棚番号 | 6列目 |
| ステータス | 7列目 |
| 備考 | 8列目 |
| 販売先 | 9列目 |

> 仕入価格・売上価格はExcel側に列がないため、取り込み後に個別入力が必要です。

### 9. CSV出力

全商品データをShift-JIS（BOM付き）のCSVとしてダウンロードできます。Excelで開いて確認・バックアップに使用してください。

## データ保存について

データはブラウザのlocalStorageに自動保存されます。

- 保存キー: `fc_ledger_v3`（商品データ）、`fc_inv_v3`（棚卸チェック）
- 実用上限の目安: **約5MB**（通常の使用で数千件まで問題なし）
- 画面左下のストレージバーで使用量を確認できます
- 容量が逼迫してきたら、CSVエクスポートでバックアップのうえ、古いデータを整理してください

> データはそのブラウザにのみ保存されます。別のPC・別のブラウザでは引き継がれません。複数端末で使う場合はCSV→Excelインポートで移行してください。

|---|---|
| 動作環境 | Chrome（ローカルHTMLファイル） |

| アイコン | Tabler Icons 2.47.0（CDN） |
| バーコード | SVG手描き（Code128風） |
| 印刷 | ブラウザ印刷（window.print） |
