## 1. システム概要

### 構成ファイル

| ファイル | 用途 | 配置先 |
|---|---|---|
| `商品管理台帳_v6.html` | PC用メインアプリ（商品台帳・売上管理・棚卸・インポート・設定） | 各PC（Chromeで開く） |
| `scan.html` | iPhone用QRスキャン画面（商品照会・棚卸スキャン） | Netlify Drop でHTTPS配信 |
| `gas_server.gs` | Google Apps Scriptサーバー（Sheets API中継） | GASエディタに貼り付け |
| `README.md` | このドキュメント | 任意（運用マニュアル） |

### データフロー

```
┌──────────────────────┐  ┌──────────────────────┐
│ 1台目PC v6.html       │  │ 2台目PC v6.html       │
│ localStorage (PC内)   │  │ localStorage (PC内)   │
└──────────┬───────────┘  └──────────┬───────────┘
           │                          │
           └────────GAS API───────────┴───────┐
                                              │
              ┌───────────────────────────────▼──────────────┐
              │ Google Apps Script Web App                   │
              │ （シークレットキー認証）                       │
              └───────────────────┬──────────────────────────┘
                                  │
              ┌───────────────────▼──────────────────────────┐
              │ Googleスプレッドシート                        │
              │ products / inv_checked / inv_scan            │
              └───────────────────▲──────────────────────────┘
                                  │
              ┌───────────────────┴──────────────────────────┐
              │ iPhone scan.html（Netlify HTTPS）             │
              │ IndexedDB（棚卸スキャン履歴）                  │
              └───────────────────────────────────────────────┘
```

### 主な特徴

- **OAuth・Google Cloud Console 不要** — Googleアカウントだけで動作
- **オフライン耐性** — localStorage と IndexedDB に常時保存（ネット断でもデータ消失なし）
- **デュアル保存モード** — 編集2秒後に自動でクラウドへ反映
- **2台同時運用対応** — 同一スプレッドシートを複数端末から参照

## 2. 初回セットアップ手順（所要15〜20分）

### 全体の流れ

| STEP | 内容 | 所要時間 |
|---|---|---|
| 1 | Googleスプレッドシート新規作成 | 1分 |
| 2 | GASエディタに gas_server.gs を貼り付け | 3分 |
| 3 | SECRET_KEY をランダム文字列に書換 | 1分 |
| 4 | Webアプリとしてデプロイ → URL取得 | 5分 |
| 5 | 商品管理台帳の「設定」タブに登録 | 2分 |
| 6 | シート初期化 → 既存データをアップロード | 3分 |

### STEP 1. Googleスプレッドシート新規作成

1. ブラウザで [https://sheets.new](https://sheets.new) を開く
2. 業務用Googleアカウントでログイン
3. ファイル名を設定（例：「府中センター 商品管理台帳DB」）

> アプリ側が起動後に `products / inv_checked / inv_scan` の3シートを自動作成します。

### STEP 2. GASエディタを開き、gas_server.gs を貼り付け

1. スプレッドシートの上部メニュー **拡張機能 → Apps Script** をクリック
2. 新しいタブでGASエディタが開く
3. 「コード.gs」の中身（`function myFunction() {...}`）を全削除
4. 同梱の `gas_server.gs` を全文コピーして貼り付け
5. プロジェクト名を変更（例：「商品管理台帳 v6 GAS API」）
6. 「保存」アイコン（フロッピー）をクリック

### STEP 3. SECRET_KEY を任意の文字列に書き換える

GASエディタ上で冒頭付近を探す：

```js
const SECRET_KEY = 'CHANGE_ME_TO_LONG_RANDOM_STRING';
```

これを任意の長いランダム文字列に書き換える（**最低20文字、英数字推奨**）：

```js
const SECRET_KEY = 'fc-ledger-7H3kPq9NmZ2VxR4tBnQ8';
```

> ⚠ このシークレットキーは後ほどHTML側にも入力します。**両方を完全一致**させることで通信を保護します。  
> メモ帳など安全な場所に控えておいてください。

保存（Ctrl+S）。

### STEP 4. Webアプリとしてデプロイ

1. GASエディタ右上の **デプロイ → 新しいデプロイ**
2. 「種類の選択」（歯車）→ **ウェブアプリ** を選択
3. 設定：
   - **次のユーザーとして実行**: ★「自分」
   - **アクセスできるユーザー**: ★「全員」  
     ※ シークレットキーで保護するため「全員」にしてOK
4. 「デプロイ」をクリック
5. 初回はアクセス許可ダイアログ：
   - 「アクセスを承認」 → アカウント選択
   - 「このアプリは Google で確認されていません」警告 → 左下「詳細」 → 「（プロジェクト名）に移動（安全ではないページ）」 → 「許可」
6. デプロイ完了画面で表示される **ウェブアプリ URL** をコピー  
   例：`https://script.google.com/macros/s/AKfycby.../exec`

### STEP 5. 商品管理台帳アプリの「設定」タブに登録

1. `商品管理台帳_v6.html` をChromeで開く
2. ナビバーの **設定** タブをクリック
3. 「接続情報」カードに：
   - **GASデプロイURL**：STEP 4 でコピーしたURL
   - **シークレットキー**：STEP 3 で設定したランダム文字列
4. 「**保存**」をクリック
5. 「**接続テスト**」をクリック → 緑のトースト「**GASへの接続に成功しました**」が出ればOK

### STEP 6. シート初期化 → 全件アップロード

1. 「データ操作」カード → **シート構成を初期化** をクリック  
   → `products / inv_checked / inv_scan` の3シートが自動作成される
2. **localStorage → クラウド（全件アップロード）** をクリック  
   → 確認ダイアログ「OK」 → ローカルの全商品がスプレッドシートに書き込まれる
3. 「処理ログ」カードで進行状況確認

## 3. iPhone用 scan.html のセットアップ（Netlify Drop）

scan.html は iPhone Safari でカメラを使うため **HTTPS配信が必須** です。Netlify Drop の無料プランで簡単にホスティングできます。

### 3.1 Netlify アカウント作成（初回のみ）

1. [https://app.netlify.com/signup](https://app.netlify.com/signup) を開く
2. メールアドレス＋パスワード or GitHubアカウントで登録（無料・クレジットカード不要）
3. メール認証を完了

### 3.2 scan.html をアップロード

1. ログイン後、[https://app.netlify.com/drop](https://app.netlify.com/drop) を開く
2. `scan.html` をドラッグ&ドロップ
3. 数秒でデプロイ完了 → URL が発行される（例：`https://joyful-pie-918992.netlify.app`）
4. アクセス用URL：`https://〇〇〇〇.netlify.app/scan.html`

### 3.3 iPhoneでURLを開く

URLをiPhoneに渡す方法（いずれか）：

- **メール**：自分宛にURLをメール → iPhoneで開いてリンクをタップ
- **QRコード**：PC側でURLをQR化してiPhoneで読み取る
- **手入力**：URLをiPhone Safariのアドレスバーに直接入力

### 3.4 iPhone Safariで初回設定

1. 右上の歯車アイコン（⚙）をタップ → 設定画面が下から出てくる
2. 入力：
   - **GASデプロイURL**：商品管理台帳と同じURL
   - **シークレットキー**：同じ値
   - **棚卸対象月**：当月のまま
3. 「**保存**」 → 「**接続テスト**」 → 緑のトースト「接続OK」を確認
4. 「**商品データを取得（getAll）**」 → キャッシュ件数が表示されればOK
5. 設定画面を閉じる

### 3.5 scan.html の更新方法

`scan.html` を修正した場合、Netlifyダッシュボードで再アップロード：

1. Netlifyにログイン → 該当サイトを選択
2. 「**Production deploys**」カードのドロップエリアに新しい `scan.html` をドラッグ&ドロップ
3. 10〜30秒でデプロイ完了（**URLは変わりません**）
4. iPhone Safari でページをリロード（下に引っ張って更新）

## 4. 2台目PCの追加手順

### 必要なもの

- 2台目PCにGoogle Chrome
- 業務用Googleアカウントが **スプレッドシートの編集者** 権限を持っていること
- 1台目で使っている GASデプロイURL と シークレットキー

### 手順

1. **ファイルコピー**：USB/共有フォルダ/メール等で `商品管理台帳_v6.html` を2台目PCに転送
2. **Chromeで開く**：ヘッダー右上のクラウド状態が「未設定」（黄）になっているはず
3. **設定タブで接続情報を入力**：1台目と同じ GAS URL/シークレットキー → 「保存」 → 「接続テスト」
4. **クラウドから取得**：「データ操作」カード → **クラウド → localStorage（全件取得）** → 全商品データがダウンロードされる
5. **デュアル保存モードON**：以後の編集を自動でクラウドへ反映
6. **商品台帳タブで件数確認**：1台目と一致していればセットアップ完了

> 既存のiPhoneは何も変更不要です。GAS URLが同じなので、どちらのPCの変更でもiPhone側に反映されます。

## 5. 日常運用ガイド

### パターンA: デュアル保存モード（推奨・自動）

両PC・iPhoneすべて同一GASに接続済みの状態で、PC側でデュアル保存モードをONにする。

**作業フロー**

- 朝の作業開始時：「クラウド → localStorage（全件取得）」を一度実行（前日の他端末の変更を取り込む）
- 作業中：商品登録/編集/売上登録/棚卸チェックは普通に行うだけ → 約2秒後に自動でクラウドへ反映
- 「設定」タブの処理ログに「自動同期完了」と出れば成功

### パターンB: 手動同期（明示的・確実）

- 作業開始時：**クラウド → localStorage（全件取得）**
- 作業終了時：**localStorage → クラウド（全件アップロード）**
- どちらか1台でしか書き込まないようにすると競合ゼロ

### 競合した場合（last-write-wins）

- 同じ商品を両方のPCでほぼ同時に編集すると、**後にアップロードした方が勝ち**
- 重要な編集前にはCSV出力でローカルバックアップ推奨

### iPhone棚卸の運用フロー

1. 倉庫巡回前：scan.html を Safari で開いて「**商品データを取得**」（最新を取り込み）
2. 「**棚卸スキャン**」モード → カメラ起動 → 各商品のQRをスキャン  
   → 件数がリアルタイムでカウントされる
3. 巡回終了後：**PC側に送信** をタップ → `inv_scan` シートに一括アップロード
4. 月末：**照合レポート** → 4分類（一致/未スキャン/不明品/販売済なのにスキャン）の.xlsxがダウンロード

## 6. トラブルシューティング

### 商品管理台帳（v6.html）

| 症状 | 対処 |
|---|---|
| 接続テストで「GASから不正な応答（HTMLが返されました）」 | GASデプロイURLが間違っている / デプロイが「ウェブアプリ」でない |
| 接続テストで「Invalid secret」 | シークレットキーが HTML側 と GAS側 で食い違っている。完全一致を確認 |
| 「SECRET_KEYが設定されていません」 | gas_server.gs の SECRET_KEY を初期値から変更して再デプロイ |
| シート初期化で「You do not have permission」 | デプロイで「次のユーザーとして実行: 自分」になっていない |
| デュアル保存ONなのに反映されない | 処理ログで「自動同期エラー」を確認。GAS URL/シークレット未設定だとスキップされる |
| 別PCで取得しても件数が古い | デバウンス2秒。直前の操作からすぐ取得すると未反映の場合あり |

### iPhone（scan.html）

| 症状 | 対処 |
|---|---|
| カメラ起動で画面が真っ黒 | Safari設定 → カメラ → 「許可」を確認。他アプリのカメラ使用中なら終了 |
| カメラ権限ダイアログが出ない | scan.html を **Netlify経由のHTTPS URL** で開いているか確認（file:// では権限制限あり） |
| QRが読み取れない | 「画像から読取」で印刷物の写真を試す。読めれば検出器は正常 |
| 商品が見つからない | 設定 → 「商品データを取得」で最新化 |
| PC側に送信が失敗 | 設定タブ → 接続テスト。`inv_scan` シートが存在するか確認 |

## 7. GASスクリプトの更新方法（バグ修正・機能追加時）

1. GASエディタを開き、コードを編集して保存
2. 右上 **デプロイ → デプロイを管理**
3. 既存デプロイの **鉛筆（編集）** アイコン
4. バージョン：「新バージョン」
5. 「デプロイ」

> URLは変わらないので、HTML側の設定変更は不要です。  
> ⚠ 「新しいデプロイ」を作るとURLが新しくなるので、必ず「デプロイを管理」から既存を編集してください。

## 8. セキュリティに関する留意事項

- **GAS は「全員アクセス可能」** にしているが、**シークレットキーで実質的なアクセス制御**を行う
- シークレットキーは長くランダムなものを使用し、外部に漏らさない
- スプレッドシートの共有設定は「特定のユーザー」または社内ドメイン限定にする
- PC譲渡・廃棄時は Chrome の Site data を消去（DevTools → Application → Storage → Clear）

## 9. 内部仕様（参考）

### シート構成

| シート | 用途 |
|---|---|
| `products` | 商品データ（全件） |
| `inv_checked` | PC側棚卸チェック状態 |
| `inv_scan` | iPhoneスキャン結果 |

### `products` シート列順

`id, name, brand, model, cat, rank, shelf, date, cost, cond, status, channel, saleDate, salePrice, desc, vendor(JSON), createdAt, updatedAt`

### localStorageキー

| キー | 内容 |
|---|---|
| `fc_ledger_v3` | 商品データ |
| `fc_inv_v3` | 棚卸チェック |
| `fc_gas_url` | GAS URL/シークレット/同期モード設定 |

### IndexedDB（scan.html）

- DB名：`fc_scan_v3`
- ストア：`scans` (keyPath: scan_id)
- 列：`scan_id, scanned_id, scanned_name, scanned_rank, scanned_at, device, inventory_month, uploaded, upload_at`

### GAS API エンドポイント

| メソッド | アクション | 用途 |
|---|---|---|
| GET | `?action=ping` | 接続確認 |
| POST | `action=init` | シート構成を初期化 |
| GET | `?action=getAll` | products 全件取得 |
| POST | `action=saveAll` | products 全件上書き |
| POST | `action=addOne` | products に1件追加 |
| POST | `action=updateOne` | 管理番号で1件更新 |
| POST | `action=deleteOne` | 管理番号で1件削除 |
| GET | `?action=getInvChecked` | 棚卸チェック取得 |
| POST | `action=saveInvChecked` | 棚卸チェック上書き |
| GET | `?action=getInvScan` | スキャン結果取得 |
| POST | `action=addInvScan` | スキャン結果追加（配列OK） |

全リクエストに **シークレットキー** 必須：

- GET: クエリ `?secret=YOUR_SECRET`
- POST: bodyのJSONに `{secret: "YOUR_SECRET", action: "...", data: ...}`
